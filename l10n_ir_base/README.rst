**This module serves as the foundational base for all modules supporting
regional requirements for Iran.**

**Features implemented in this module:**

\* **Persian Numbers in Reports:** Automatically converts numbers
(Integers, Floats) and dates to Persian digits in all standard reports
(PDF/HTML) for users with the Persian language set. \* **Field
Support:** Handles the conversion of various field types, including
Relational fields (Many2one, Many2many, One2many). \* **Persian Grouping
Labels:** Enhances the grouping interface (e.g., in Sales or Pivot
views) by displaying date and time group labels in the Jalali (Persian)
calendar format. \* **Localization Core:** Provides essential base
classes and utilities required for other Iranian localization modules.

Use Cases / Context
===================

This module is designed to localize Odoo reports and prints for the
Persian language. By default, Odoo displays numbers and dates in English
format. This module modifies the core QWeb converters to automatically
convert all numerical data in PDF and HTML outputs to Persian digits.

**Key Features:** \* Automatic conversion of Integers. \* Automatic
conversion of Floats. \* Automatic conversion of Date and Datetime
fields. \* Support for Relational fields: Many2one, Many2many, and
One2many.

Installation
============

Install the module from the Apps menu.

Configuration
=============

No configuration is required. Once installed, number conversion is
automatically activated for reports generated by users with the language
set to fa_IR.

Usage
=====

After installation, simply ensure the user's language is set to
"Persian" (Farsi). All standard reports (such as Sales Orders, Invoices,
etc.) will display numbers and dates in Persian format automatically.

Development
===========

This module works by overriding (extending) the standard ir.qweb.field
classes. The number conversion logic utilizes the persiantools library.

To use the conversion function in your own Python code:

:literal:`\`python      from persiantools import digits      fa_number = digits.en_to_fa(12345)`\ \`

Known issues / Roadmap
======================

**Group By:** We have currently added a Persian grouping feature that
displays labels in Persian. However, there is an existing issue
regarding the time difference between the Jalali (Persian) and Gregorian
calendars. This needs to be resolved at the database level.
