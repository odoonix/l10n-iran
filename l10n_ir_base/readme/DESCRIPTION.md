**This module serves as the foundational base for all modules supporting regional requirements for Iran.**

**Features implemented in this module:**

*   **Persian Numbers in Reports:** Automatically converts numbers (Integers, Floats)
and dates to Persian digits in all standard reports (PDF/HTML) for users with the
Persian language set.
*   **Field Support:** Handles the conversion of various field types, including
Relational fields (Many2one, Many2many, One2many).
*   **Persian Grouping Labels:** Enhances the grouping interface (e.g., in Sales or
Pivot views) by displaying date and time group labels in the Jalali (Persian) calendar
format.
*   **Localization Core:** Provides essential base classes and utilities required for
 other Iranian localization modules.
