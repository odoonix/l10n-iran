This module is designed to localize Odoo reports and prints for the
Persian language. By default, Odoo displays numbers and dates in English
format. This module modifies the core QWeb converters to automatically
convert all numerical data in PDF and HTML outputs to Persian digits.

**Key Features:** \* Automatic conversion of Integers. \* Automatic
conversion of Floats. \* Automatic conversion of Date and Datetime
fields. \* Support for Relational fields: Many2one, Many2many, and
One2many.
